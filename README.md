**公益主题 AI 短片｜代际理解 · 青年成长 · 家庭支持**

[▶ 点击观看完整短片](./short-film.mp4)

> 我们曾经以为，父亲无所不能。  
> 后来才知道，他也曾是一个第一次面对世界的年轻人。

## 作品简介

小时候，他觉得父亲什么都会；长大后，他觉得父亲什么都不懂。直到独自面对工作、住房与未来的压力，他才从旧工具箱、账本和照片中，看见父亲年轻时同样无措的模样。

《摸着黑往前走》以父子关系为线索，将两个时代的青年处境交织在一起，讲述普通人在未知中承担责任、彼此支持的故事。作品希望呈现：当生活暂时没有答案，理解与陪伴仍然能让人继续向前。

## 创意与视觉设计

- **双时空叙事**：以当代儿子与年轻父亲的生活相互映照，通过相似的困境建立代际共鸣。
- **生活化细节**：以修玩具、整理行李、翻看账本、教用手机等日常场景承载情绪。
- **色彩变化**：过去采用温暖、质朴的记忆色调，现在偏向冷色与城市疏离感，结尾逐渐融合。
- **镜像画面**：将两个时代的出租屋、书桌与人物并置，让不同年代的年轻人在同一画面中面对未知。

## 创作流程

**主题构思 → 剧本与分镜 → 视觉参考与关键帧 → AI 视频生成 → 素材筛选与修改 → 剪辑与声音处理 → 成片**

制作中重点关注人物形象的一致性、动作的自然度、镜头之间的衔接，以及画面与叙事情绪的配合。根据镜头需求调整提示词、筛选生成结果，再通过剪辑组织故事节奏。
